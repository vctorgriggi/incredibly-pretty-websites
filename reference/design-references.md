# Design references without subscriptions

Start with the brief, supplied assets and the nearest design system. For a new landing,
[taste-informed.md](taste-informed.md), [foundations.md](foundations.md) and the direction
contract can support a complete direction. External research answers unresolved visual
questions; it is not a fixed quota of sources or a prerequisite to authoring.

## Choose a source

| Need | Starting point |
| --- | --- |
| A concrete hierarchy, crop or responsive treatment | The comparable product's own public site |
| Established product conventions | Its official design system, such as [Geist](https://vercel.com/geist), [Primer](https://primer.style), [Carbon](https://carbondesignsystem.com) or [GOV.UK](https://design-system.service.gov.uk) |
| Discover a relevant composition | [SiteInspire](https://www.siteinspire.com), [One Page Love](https://onepagelove.com), [Minimal Gallery](https://minimal.gallery) or [Httpster](https://httpster.net) |
| Find an existing design analysis | [Official DESIGN.md collection](https://github.com/VoltAgent/official-design-md) or [community analyses](https://github.com/VoltAgent/awesome-design-md) |

These links are discovery aids, not claims that their current content, access or prices
were checked for this job. Confirm the specific source you use. Community analyses are
interpretations, not official brand tokens. A gallery thumbnail does not prove motion,
responsive behavior or a working interaction. Stop at a login or access refusal and
continue with already available guidance when sufficient; never bypass the restriction.

## Inspect only what the decision needs

Use the session's configured public acquisition capability and research policy to read
pages. Use the available browser for visual evidence and computed-style inspection.
Do not introduce a parallel scraper or run another coding agent to obtain these tools.
The optional [brand-capture.js](brand-capture.js) can measure rendered styles through
an existing browser runner; measurements still require visual interpretation.

Record composition, focal medium, type hierarchy, density, accent roles and the relevant
mobile behavior. Inspect the actual image when claiming a visual reference. Extract
principles, not copied branding, text, layout code or unlicensed client imagery.

## Keep a bounded direction record

Choose one primary source and at most two supporting sources. A source can be:

- a named bundled reference you actually read, with its path, section and content hash;
- a supplied client constraint or asset;
- a public page you actually opened, with its URL and inspection date.

Preserve three to five useful traits. Specify what each secondary source contributes,
what you reject, the role of media and colors, and how the composition works on mobile.
Record a short `decision | source | role | why` ledger. A local craft rule is design
rationale, not a claim that a live reference screen was inspected.

Use existing project artifact schemas when they define this record. Reuse the same
record during repairs and inspect the rendered result against it. Do not inflate the
ledger with sources that did not change a decision.
